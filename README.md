# Проект OOP_14_1_Homework

## Описание:

Проект OOP_14_1_Homework представляет код разработанный на основе классов, с целью создания программы электронная коммерция "e-commerce" для электронного магазина.

## Установка:

1. Клонируйте репозиторий из PyCharm:
```
gh repo clone KlimanovGrigoriy888/OOP_homework
```
2. Проверьте имеется ли у вас менеджер зависимостей poetry выполнив команду:
```
poetry --version
```
3. Если в PyCharm нет poetry установите Poetry через команду:
```
pip install poetry
```
4. Для установки зависимостей проекта из файла pyproject.toml исполните команду:
```
poetry install
```
5. Для работы фреймворка pytest и pytest-cov необходимо в PyCharm добавить эти фреймворки. Наберите команду в терминале:
```
poetry add --group dev pytest pytest-cov
```



## Использование:

1. Клонируйте код в PyCharm, так как проект не имеет конечной функции, то здесь опишу реализованные функции в модулях.
2. В модуле base_product реализован Абстрактный класс BaseProduct который является родительским для классов продуктов, все наследуемые классы должны содержать:
* метод инициализации основных параметров продукта методом __init__,
* метод __str__- магический метод для вывода информации об объекте класса продукта,
* метод __add__ - сложения суммарной стоимости продукта с суммарной стоимостью другого продукта. 
3. В модуле products.py являющийся дочерним от BaseProduct:
* реализован Класс для описания продукта с атрибутами название (name), описание (description), цена (price), количество в наличии (quantity).
* реализован класс-метод "new_product()" с помощью декоратора "@classmethod" для добавления продукта с проверкой наличия такого же товара схожего по имени через атрибут класса "added_category_products" в виде словаря в котором ключом является название продукта, а значение списком, где 0 индекс это количество продукта, 1 индекс это последняя цена.
* добавлен вызов ошибки в класс Product и его дочерние ValueError в случае добавления продукта с нулевым количеством.
При добавлении продукта и конфликте цен из списка и новой цены метод выбирает ту цену, которая является более высокой.
* Реализован метод геттер с помощью декоратора "@property" для приватного атрибута цены с целью вывода данных цены.
* Реализован метод сеттер для атрибута экземпляра класса с помощью декоратора "@price.setter" для ввода новой цены с проверкой.
 В случае если цена равна или ниже нуля, в консоль выводится сообщение “Цена не должна быть нулевая или отрицательная”. Так же реализованна
проверка вводимой цены на значение. Если цена товара понижается, добавлена логика подтверждения пользователем вручную через ввод y (значит yes) или n (значит no) для согласия понизить цену или для отмены действия соответственно, при этом новую цену устанавливать не нужно.
* Реализован магический метод '__str__' для вывода информации об объекте класса продукта в виде 'Название продукта, хх руб. Остаток: хх шт.'.
* Реализован магический метод '__add__' для возможности складывать суммарную стоимость классов продукт для получения общей суммы сложенных продуктов. В магический метод сложения суммарной стоимости продукта с суммарной стоимостью другого продукта добавлена проверка равенства родства класса.

4. В модуле category.py
* Реализован Класс для описания категории продукта с атрибутами название (name), описание (description), список товаров категории (products). Так же в этом модуле созданы атрибуты класса счетчик категорий продукта (category_count) и счетчик всех продуктов в категории продукта (product_count).
* Атрибут продукта типа класс Product сделан приватным.
* Реализован отдельный метод класса Сategory с названием "add_product()" для добавления продукта в приватный атрибут продукта products с проверкой принадлежности добавленного продукта к родительскому классу Product
* Реализован метод атрибута под названием "products" с помощью которого возможно посмотреть приватный атрибут продукта в виде "Название продукта, X руб. Остаток: X шт.\n", в данном методе используется вызов магического метода из класса Product '__str__' с помощью функции str().
* Реализован магический метод '__str__' для вывода информации об 'Название категории, количество продуктов: ххх шт.' Количество продуктов подсчитывается из общего числа всех продуктов на складе для категории продукта перебором списка класса продуктов и сложения их количества.
* Реализован дополнительный метод атрибута под названием "products_list" с помощью которого создается список продуктов в категории продукта. Реализован для использования в классе 'ProductIterator' для вывода продуктов с помощью итерации по товарам, которые хранятся в данной категории.
* Добавлен новый метод middle_price() который подсчитывает средний ценник всех товаров категории продукта с обработкой ошибки при нулевом количестве добавленных товаров, так как при подсчете делить на ноль нельзя.

5. В модуле products_iterator.py
* реализован Класс который принимает экземпляр класса категории продукта и возвращает итератор для перебора класса продуктов из класса категории продукта.

6. В модуле lawngrass реализован класс LawnGrass наследник от класса Product для создания продуктов типа растение-трава с расширенными
    атрибутами: country - Страна, germination_period - Срок прорастания, color - Цвет. В магический метод сложения суммарной стоимости продукта с суммарной стоимостью другого продукта добавлена проверка равенства родства класса.
7. В модуле smartphone реализован класс Smartphone наследник от класса Product для создания продуктов типа смартфон с расширенными атрибутами:
    efficiency- Производительность, model - Модель, memory - Объем встроенной памяти, color - Цвет."". В магический метод сложения суммарной стоимости продукта с суммарной стоимостью другого продукта добавлена проверка равенства родства класса.
8. В модуле print_mixin реализован класс PrintMixin это класс типа mixin, который используется как класс родитель новой функциональности. В нем реализован метод для вывода информации в формате "Название класса, (название продукта, описание продукта, цена, количество)" при создании нового объекта класса и объявлен классом родителем в классе наследнике.
В этом проекте все классы типа продукт используют его функциональность как от родительского класса.
## Тестирование:

1. В пакете tests реализованны функции тестирования всех функций пакета src. Тест покрывает 90% кода функций.
2. Для просмотра тестов создан файл htmlcov в корне проекта.
4. Для выполнения и просмотра результата всех выполненных тестов необходимо написать команду терминале:
```
poetry run pytest --cov

```
5. Для формирования отчета в HTML формате и создания файла htmlcov, необходимо написать команду в терминале:
```
pytest --cov=src --cov-report=html

```
